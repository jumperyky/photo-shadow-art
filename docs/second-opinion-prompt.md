# 他のAIに同じ市場調査を依頼するためのプロンプト

## 使い方

- **§1 をそのままコピペ**して、ブラウジング機能が有効な別のAI（ChatGPT / Gemini / Perplexity / Claude別セッション等）に渡す。
- §1 には**こちら側の調査結論を一切含めていません**。含めると相手がそれに同意するだけの追認機になり、
  セカンドオピニオンの意味が消えるためです。
- §2 は**相手に渡さず、自分の手元で答え合わせに使う**ためのチェックリストです。
- §3 は相手の回答が浅かったときの追い込み用の追加質問です。

---

## §1. コピペする本体プロンプト

```
あなたは日本市場に詳しい事業リサーチャーです。以下の個人事業について、実データに基づく市場調査を
してください。おだてる必要はありません。勝ち目がないなら「ない」と根拠付きで言ってください。

## 前提: 何を売ろうとしているか

私は自宅に3Dプリンタ（Bambu Lab A1 mini、造形サイズ180×180×180mm）を1台持っている個人です。
これ1台だけで、以下の2種類の「写真を立体造形物にした作品」を制作・販売しようと考えています。

【商品A: 線幅変調シャドウアート】
- 一定ピッチ・一定角度の平行線（リッジ）を並べた平板
- 各線の太さを、その位置の元写真の明度に応じて変える
  （暗い部分＝太い線・隙間が狭い / 明るい部分＝細い線・隙間が広い）
- 外枠（四角・円・六角形など）でクリップし、枠自体もリング状のリッジとして線同士をつないで
  1つの印刷可能な形状にする
- 一定の厚みで押し出す
- 「ラインスクリーン(line screen)」と呼ばれる手法。斜めから光を当てる/影を落とすと
  写真のような像が浮かび上がる。バックライトは不要で、壁に掛けるだけでも成立する
- 現行の想定仕様: デザイン部150mm角＋外枠8mm幅＝外形166mm角、厚み2mm、線48本、線幅0.5〜2.9mm
- 私は自分でこの形状を生成するPythonスクリプトを書いており、STL出力まで動いている

【商品B: リソフェイン（lithophane、日本語では「リトフェイン」「リトファン」表記も）】
- 画素ごとに厚みを変え、透過光量で濃淡を出す写真パネル。バックライト（LED）が必須
- 商品Aとは別物。こちらは無料ツールでも生成できることは把握している

【商品C（検討中）: 赤ちゃんの手形・足形を実寸大の立体アートにしたもの】
- 親が家で紙とインクで取った手形をスマホで撮影 → その画像から造形、というフローを想定

## 前提: 誰に売るか

- 生まれたての子供の写真や、子供の写真を飾りたい親御さん
- 「普通の写真プリントでは飽きている」層
- 集客はInstagram中心を想定（現時点でフォロワーは0）
- 私は個人（副業規模）。大量生産はできない

## 調査してほしいこと

### 【最優先】1. 日本国内マーケットプレイスの実データ

必ず実際にサイトを開いて、目で見た数字を報告してください。検索エンジンの要約で代替しないでください。
「アクセスできなかった」場合は、そう正直に書いてください（推測で埋めないこと）。

- minne（minne.com）、Creema（creema.jp）、メルカリ（jp.mercari.com）、Etsy、BASE、STORES で
  以下の語を検索し、**出品件数・価格帯（最安/最高/ボリュームゾーン）・各商品のレビュー件数**を報告:
  「リトフェイン」「リソフェイン」「lithophane」「3Dプリント 写真」「シャドウアート」
  「ラインアート 写真」「手形足形アート」「立体手形」
- **レビュー件数は特に重要です。**出品はあってもレビューが0件ばかりなら「出品はあるが売れていない」
  ことの証拠になります。件数を必ず拾ってください。
- minneの「ベビー・キッズ ＞ メモリアル・記念品」カテゴリを人気順で見て、
  実際に売れている商品の種類・価格帯を報告してください。
- **メルカリの「売却済み（SOLD）」**を確認してください。ここは「実際に売れた価格」が分かる
  唯一の場所です。売却済みの件数と価格帯を報告してください。
- Creemaには「作品プロモーション」という有料広告機能があります。広告を出している商品は
  採算が取れている可能性が高いので、該当があれば報告してください。

### 2. 価格相場（サイズ・形状別）

- 商品A・Bについて、国内外の販売価格をサイズ別・形状別（平板/曲面/ランプシェード/
  ナイトライト一体型/キーホルダー/ハート型など）に表で整理。LED・フレーム込みかを明記。
- 海外（Etsy/eBay）と国内の価格差。どちらが高いか、その理由の考察。
- 為替は1USD=155円と仮定して円換算を併記（仮定であることを明記）。

### 3. 原価と生産キャパ（計算過程を必ず示す)

- 上記の形状仕様（166mm角・厚み2mm・線パターン）から**PLA使用量を体積計算で推定**してください。
  PLA密度1.24g/cm³。線パターンの被覆率は仮定を明記した上で計算過程を式で示してください。
- 日本国内のPLAフィラメント1kgの実売価格（2026年時点）を調べ、1個あたり材料費を円で。
- Bambu Lab A1 miniでこのサイズ・厚みを印刷する所要時間の実例報告を探してください。
- A1 miniの消費電力の実測報告 × 日本の電気料金単価で1個あたり電気代。
- 送料（クリックポスト/ゆうパケット/ネコポス/宅急便コンパクトの2026年の実料金）、
  梱包材費、プラットフォーム手数料（minne/Creema/BASE/メルカリの最新料率）。
- 販売価格 3,000 / 5,000 / 8,000 / 12,000円 での粗利表。人件費を時給1,200円の
  機会費用として差し引いた実質利益も出してください。
- **180mmという造形サイズ制約**が商品ラインに与える影響（作れる最大サイズ、
  A4以上をやる場合の分割パネル化の必要性とそのデメリット）。
- A1 mini 1台で月に現実的に作れる個数と、稼げる金額のレンジ。
  ※ここで「キャパ上限＝売上見込み」と混同しないこと。需要側の制約は別途4で評価してください。

### 4. 需要の実在性（ここを厳しく見てください）

- そもそも日本にこの商品の需要が存在する証拠はありますか。
  「リトフェイン」「リソフェイン」「手形足形アート」「立体手形」等の
  **検索ボリューム**（Googleトレンド/キーワードプランナー等）を調べてください。
- 国内の出品が少ない場合、それは「誰も気づいていないから」なのか
  「やってみたが売れないから」なのか。**両者を区別できる証拠を探してください。**
  区別できないなら「区別できない」と書いてください。
- 日本の出生数の最新値、ベビー関連市場規模、ニューボーンフォト市場の動向。
- 出産祝い/内祝い/お七夜/お食い初め/ハーフバースデー/初節句/敬老の日など、
  日本特有のギフト需要イベントと典型的な予算相場（内祝いの「半返し」慣習を含む）。

### 5. 競合

- 商品Cに近い「立体手形足形」サービスの既存事業者と価格。
  制作方式（物理型取り＋石膏/樹脂キャストか、3Dスキャンか、3Dプリントか）も必ず調べてください。
  方式が違えば同じ商品ではないので、価格比較の前提が変わります。
- 商品A・Bを実際に販売している日本の個人作家・法人。フォロワー規模、価格提示の有無。
- **参入障壁の評価**: 同じものを作れる無料ツールやプリンタ標準機能が存在するか。
  Bambu Lab の純正ソフトウェアやフィラメント製品ラインに、この用途を直接サポートするものが
  あるかを必ず確認してください。あるなら差別化可能性への影響を論じてください。

### 6. 手形足形（商品C）の技術的成立性

- 「紙にインクで取った平面の手形をスマホ撮影した2D画像」から立体化する場合、
  何が失われ、何が再現できるのか。既存競合の物理型取り方式と比べて何が劣るのか。
- 新生児の手・足の実サイズ。180mmの造形サイズに収まるか。
- 上記【商品A】のラインスクリーン方式（一定ピッチの平行線の太さを変える手法）で
  手形を表現しようとすると何が起きると予想されますか。
  線ピッチと指の幅の関係から具体的に論じてください。
- 乳幼児が触る可能性のある造形物としての安全性（PLAの安全性、誤飲、PL法）。

### 7. Instagram集客の現実的な数値

- ベビー・キッズ・ハンドメイド・メモリアルグッズ領域での、
  フォロワー数と月商の関係の実例（出典明記の上で参考値として扱う）。
- リール/投稿のリーチ・エンゲージメント率の2025〜2026年の目安。
  フォロワー0から売上が立つまでの期間。
- Meta広告（Instagram広告）の日本でのCPM/CPC/CTR。
  **月1〜3万円という少額予算で成果が出るのか**を、コンバージョン数の観点から評価してください。
- 顧客に写真をアップロードしてもらう必要があるカスタムオーダー商品のCVRについての知見。
- ハッシュタグ設計。「リソフェイン」等の商品名系タグに検索需要があるのか、
  ないならどの語を使うべきか。

### 8. 日本法での注意点（法的助言ではなく一般整理として）

- **顧客が持ち込む写真の著作権**。写真スタジオが撮影したニューボーンフォト等の場合、
  著作権は誰にあり、加工・商品化は何の権利に触れるのか。ここは特に厚めに論じてください。
- 子供の顔写真を預かる場合の個人情報保護法上の扱い、プライバシーポリシーの必要性。
- 顧客写真を作品事例としてSNS掲載する際の肖像権・同意の取り方。
- 特定商取引法の表示義務（個人が自宅住所を公開せずに済ませる方法を含む）。
- 景品表示法（「実寸大」「安全」等の表現）、PL法。
- **乳幼児向け製品に関する2026年の法改正・新制度**があるか確認してください。あれば
  本商品が該当しうるか、該当を避ける設計・表示は何かを論じてください。
- LEDライトベースを仕入れて同梱する場合の電気用品安全法（PSE法）の該当性。
- 副業としての税務（申告ライン、インボイス）、古物営業法の該非。

## 出力ルール（厳守）

1. **数値には必ず出典URLを付ける。** 出典のない数字は書かないでください。
2. **「確認できた事実」「推定」「不明」を明確に区別**してラベルを付けてください。
   調べて分からなかったものは、推測で埋めずに「不明」と書いてください。
   何を確認できなかったかのリストを最後に付けてください。
3. 実際にサイトを開いて確認したのか、検索結果の要約で済ませたのかを明記してください。
4. 表を活用し、日本語で書いてください。金額は円で（外貨は換算レートを明記）。
5. **私に都合のいい結論を書かないでください。** 撤退すべきなら撤退すべきと書いてください。
6. 最後に以下を明示してください:
   - 商品A・B・Cのうち**どれを主力にすべきか、その理由**
   - 推奨価格（サイズ別）
   - この事業の**最大のリスクは何か**
   - **撤退ライン**（何ヶ月後に何が起きていなければ辞めるべきか）
   - 総合評価（項目別にA〜Eで採点）
```

## §2. 手元で答え合わせに使うチェックリスト（相手には渡さない）

相手の回答が返ってきたら、以下の論点でこちらの調査と一致するか突き合わせる。
**一致しない場合、どちらが正しいかは出典の質で判断する**（一次データ > 実測 > 検索要約 > 推測）。

| # | 論点 | 見るべきポイント |
|---|---|---|
| 1 | 商品Aと商品Bのどちらを主力に推すか | 逆の結論なら、その根拠が原価か競合かを確認。判断が割れる論点なので重要 |
| 2 | リソフェインの参入障壁をどう評価したか | プリンタメーカー純正の生成機能・専用フィラメントの存在に気づいたか。見落としていたら調査が浅い |
| 3 | PLA使用量の計算結果 | 実測は150mm角・厚2mm・外形166mmで **27.1g**。大きく外れているなら被覆率の仮定を確認 |
| 4 | 造形サイズの上限 | 実測でデザイン164mm＋枠8mm＝外形180mmが限界。180mm角がそのまま作れると書いていたら枠の存在を見落としている |
| 5 | 手形足形をラインスクリーンで作った場合の予測 | 「指が線に分解されて輪郭が消える」と予測できたか。実機検証の結果と一致するか |
| 6 | 立体手形足形の既存競合の制作方式 | 物理型取り＋キャストが主流と指摘できたか。3Dプリント前提で価格比較していたら誤り |
| 7 | 需要の実在性の評価 | キャパ上限を売上見込みと混同していないか。「需要は未実証」と正直に言えているか |
| 8 | 国内の実出品件数・レビュー件数 | **ここが最大の期待値。**こちらが取れなかったデータ。数字が出てきたら最重要の追加情報 |
| 9 | メルカリSOLDの実売価格 | 同上。実際に売れた価格が分かる唯一のデータ |
| 10 | 顧客写真の著作権リスク | スタジオ撮影写真の著作権帰属に言及したか。していなければ法務が浅い |
| 11 | 2026年の乳幼児向け製品の新制度 | 消費生活用製品安全法の子供用特定製品制度（2026年7月8日施行）に到達したか |
| 12 | LED同梱時のPSE法 | 個人輸入した場合に自分が輸入事業者になるリスクに言及したか |
| 13 | 少額広告予算の評価 | 月1〜3万円では機械学習の最適化に必要なコンバージョン数が溜まらない点を指摘できたか |
| 14 | 撤退ラインの具体性 | 期間と数値で書けているか。抽象論なら実用性が低い |

### 相手の回答の質を見分けるサイン

**質が高いサイン**
- 「アクセスできなかった」「不明」を正直に書いている
- 計算過程を式で示している
- 自分の推測と事実を区別している
- こちらに不利な結論も書いている

**質が低いサイン**
- 全部の数字に出典がついているのに、そのURLが実在しない（必ず数本を開いて検証する）
- 「大きな可能性があります」「ニーズは高まっています」など、根拠のない前向き表現が多い
- 出品件数などの数字が妙にキリがいい（「約100件」等）→ 実際に見ていない疑いがある
- 撤退ラインを書かない、または曖昧にする

## §3. 回答が浅かったときの追加質問

相手の一次回答が抽象的だった場合、以下を順に投げる。

1. 「minneとCreemaで実際に検索して、**出品件数とレビュー件数の実数**を教えてください。
   アクセスできなかったなら、できなかったと書いてください。推測で数字を書かないでください。」
2. 「メルカリの**売却済み（SOLD）**を見て、実際に売れた価格を教えてください。」
3. 「この事業をやらない方がいい理由を、3つ挙げてください。」
4. 「あなたの回答の中で、**最も確度が低い数値はどれ**ですか。理由も教えてください。」
5. 「Bambu Labの純正スライサーに、この商品を生成する機能は搭載されていますか。
   搭載されている場合、差別化にどう影響しますか。」
6. 「1年目に現実的に期待できる月商はいくらですか。**キャパ上限ではなく、
   フォロワー0から始めた場合の受注見込み**で答えてください。」

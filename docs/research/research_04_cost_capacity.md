### 1-2. 使用グラム数と材料費の計算

**A．シャドウアート（外形166mm角、2mm厚）**

```
枠部体積 = (166mm×166mm − 150mm×150mm) × 2mm
        = (27,556mm² − 22,500mm²) × 2mm = 5,056mm² × 2mm = 10,112mm³

パターン部体積 = 150mm×150mm × 被覆率35%（仮定） × 2mm
             = 22,500mm² × 0.35 × 2mm = 15,750mm³

総体積 = 10,112 + 15,750 = 25,862mm³ = 25.86cm³
質量  = 25.86cm³ × 1.24g/cm³ = 32.1g
造形ロス（スカート/プライム等）+10%（仮定） → 約35g
```

材料費：35g × 2.8円/g(Basic) = **約98円**／35g × 3.3円/g(Matte) = **約116円**

**B．リソフェイン（100×150mm、平均実効厚み1.8mm＋縁枠5mm幅・3mm厚）**

```
画像パネル体積 = 100mm×150mm × 1.8mm(仮定：最大3mmの60%) = 27,000mm³
縁枠体積     = 周長500mm相当 × 幅5mm × 厚み3mm = 7,500mm³
総体積 = 27,000 + 7,500 = 34,500mm³ = 34.5cm³
質量  = 34.5cm³ × 1.24g/cm³ = 42.8g
造形ロス+10%（仮定） → 約47g
```

材料費：47g × 2.8円/g(Basic/白) = **約132円**／47g × 3.3円/g(Matte) = **約155円**

| 条件 | 目安時間 | 根拠 |
|---|---|---|
| リソフェイン、平置き・0.2mm層・5walls・80%infill（MakerWorldのA1 miniリソフェインフレームモデル実例） | **約5.9〜6.3時間** | [Bambu Labフォーラム: CMYKリソフェイン印刷時間の議論](https://forum.bambulab.com/t/question-s-on-cmyk-lithophane-printing-time-materials/151182)、MakerWorld掲載のBambu Lithophane Frameモデル |
| リソフェイン、平置き・0.1mm層 | **約10〜11時間（推定）** | 直接の実例報告は見つからず。レイヤー数がほぼ倍になることから経験的に1.6〜1.8倍と推定（仮定） |
| リソフェイン、**縦置き**（画像面を垂直にして層目を目立たなくする技法） | **15〜20時間程度（推定、実例報告なし）** | Z方向の総距離が3mm→100〜150mmへ拡大し、レイヤー数が数十倍に増加するための機械的推定。信頼できる実例報告は検索で発見できず「不明」に近い |
| シャドウアート（166mm角・線画パターン・2mm厚、0.2mm層） | **3〜5時間程度（推定）** | 直接の実例報告は発見できず「不明」。細線が多くトラベル（ヘッド移動）が多い形状特性から、薄い割に時間がかかると推定 |
| シャドウアート（0.1mm層） | **5〜8時間程度（推定）** | 同上、レイヤー数増加分を加味した推定 |

※A1 miniの一般的な印刷速度に関する参考情報として、「手のひらサイズのフィギュアが約1.5時間」「ベンチマークモデルが14分」等の報告があるが（[note.com記事](https://note.com/fine_gerbil9006/n/n7c30463272a1)）、本件サイズの平板・リソフェインに直接該当する実測レポートは限定的であり、上記は計算上の推定値であることを明記する。

## 3. 稼働キャパシティ（月間生産可能個数）

### 3-1. 1日あたり実質稼働時間（仮定）

自宅設置・個人運用という制約下で、以下2シナリオを設定する（仮定）。

| シナリオ | 内容 | 1日あたり機械稼働時間 |
|---|---| ---|
| 保守的（日中のみ監視、夜間は長尺ジョブのみ） | 生活音・近隣配慮のため深夜早朝の開始/失敗対応を避け、日中在宅時間中心に稼働 | 約12時間/日（仮定） |
| 積極的（A1 miniは比較的静音・火炎検知等の安全機構ありのため夜通し運転を許容） | 日中＋夜間无人運転を許容 | 約20時間/日（仮定） |

月間機械稼働時間（30日換算、仮定）：
- 保守的：12h×30日＝**360時間/月**
- 積極的：20h×30日＝**600時間/月**

### 3-2. 失敗率（reprint率）

大判・薄肉フラット形状（166mm角平板、100×150mmリソフェイン）は反り・初層剥離のリスクがベッド全面近くまで使うため相対的に高い。**仮定：reprint率10%**（一般的な自宅FDM運用でよく言われる目安。ベッド全面に近いフラット造形のため、通常の小物より高めに設定）。

再印刷を考慮した「販売可能1個あたりに必要な機械時間」＝ 基準印刷時間 × 1/(1−0.10) ＝ 基準印刷時間 × 1.111

### 3-3. 人手作業時間（分単位、仮定）

| 作業 | シャドウアート | リソフェイン |
|---|---|---|
| ベッドからの取り外し | 3分 | 3分 |
| ベッドクリーニング/糊再塗布 | 2分 | 2分 |
| フィラメント交換（ロール切替の按分） | 1分 | 1分 |
| バリ取り・サポート除去（線が細く繊細なため慎重な作業が必要） | 12分 | 7分（縁枠除去中心で比較的単純） |
| 洗浄（油分・粉除去、実作業時間） | 2分 | 2分 |
| 検品（元写真との照合、割れ・欠け確認） | 4分 | 4分 |
| 梱包 | 5分 | 10分（LEDベース同梱のため） |
| **合計** | **約29分/個** | **約29分/個** |

→ 人件費（時給1,200円換算）：29分＝0.483時間 × 1,200円 ＝ **約580円/個**（機会費用）。以下の粗利表ではシャドウアート500円、リソフェイン600円として簡略化して計算（作業内訳の若干の違いを反映）。

### 3-4. 月間生産可能個数（機械時間ベース）

```
販売可能個数 = 月間機械稼働時間 ÷ （基準印刷時間 × 1.111）
```

| 商品/印刷モード | 基準印刷時間 | 保守的シナリオ(360h) | 積極的シナリオ(600h) |
|---|---|---|---|
| シャドウアート（0.2mm、推定4h） | 4h | 360/(4×1.111)=**約81個** | 600/(4×1.111)=**約135個** |
| リソフェイン平置き（0.2mm、実例6h） | 6h | 360/(6×1.111)=**約54個** | 600/(6×1.111)=**約90個** |
| リソフェイン縦置き（推定16h、高品質仕様） | 16h | 360/(16×1.111)=**約20個** | 600/(16×1.111)=**約34個** |

人手作業時間の総量（例：積極的シナリオでシャドウアート135個生産の場合）＝135個×29分＝3,915分＝**約65時間/月＝1日あたり約2.2時間** → 副業として十分に許容範囲内であり、**人件費・作業時間は律速要因にならない**（＝ボトルネックは常にプリンタの印刷時間）。

## 4. 電気代

Bambu Lab公式FAQによるA1 miniの消費電力：**アイドル時約6W、印刷時平均約57W**（[Bambu Lab A1 mini FAQ](https://wiki.bambulab.com/en/a1-mini/manual/faq)、関連まとめ：[Call3D Power Consumption Guide](https://www.call-3d.com/blogs/upgrades/bambu-lab-power-consumption-review)）。

電気料金単価：**31円/kWh**（公益社団法人全国家庭電気製品公正取引協議会の目安、[新電力サーチ記事](https://qvou.com/media/average-electric-rate/)）。※2026年1〜3月は政府補助（1kWhあたり4.5円）が別途適用された時期があったが、7月時点の通常単価として31円を採用。

```
電気代 = 印刷時間(h) × 0.057kW × 31円/kWh
```

| 商品 | 印刷時間 | 電気代 |
|---|---|---|
| シャドウアート（4h） | 4h | 0.057×4×31 ≈ **7.1円** |
| リソフェイン平置き（6h） | 6h | 0.057×6×31 ≈ **10.6円** |
| リソフェイン縦置き（16h） | 16h | 0.057×16×31 ≈ **28.3円** |

→ 電気代は原価構造の中では極めて小さく、価格決定要因にはならない。

## 7. A1 mini 1台という制約下のボトルネックと月間上限額

### 7-1. ボトルネックの所在

- **律速要因は明確に「プリンタの印刷時間（1台しかない）」**。人手作業（1個あたり約29分）は月間最大生産量（積極的シナリオで135個/月）でも合計約65時間/月＝1日2.2時間程度に収まり、副業として無理なくこなせる範囲（3-4節参照）。
- 電気代・梱包資材費・プラットフォーム手数料はいずれも1個あたりのコスト構造上小さく、事業のスケールを制約する要因にはならない。
- 唯一の制約は「1台で同時に1個しか作れない」こと、かつ**大判フラット形状ゆえの反り・失敗リスク（reprint率10%仮定）**と、**リソフェインを高品質仕様（縦置き印刷）にすると印刷時間が16時間/個に跳ね上がる**ことで、商品ミックス次第で生産量が3〜7倍変動する点。

### 7-2. 月間生産可能個数と売上上限（レンジ）

| 商品構成 | 保守的シナリオ(360h/月) | 積極的シナリオ(600h/月) |
|---|---|---|
| シャドウアートのみ（4h/個） | 約81個/月 | 約135個/月 |
| リソフェイン平置きのみ（6h/個） | 約54個/月 | 約90個/月 |
| リソフェイン縦置き（高品質）のみ（16h/個） | 約20個/月 | 約34個/月 |

**「1台で月に現実的に稼げる上限額」（売上高ベース）の試算：**

- シャドウアート中心・8,000円想定：81〜135個 × 8,000円 = **約65万円〜108万円/月**
- リソフェイン（平置き）中心・8,000円想定：54〜90個 × 8,000円 = **約43万円〜72万円/月**
- リソフェイン（縦置き高品質）中心・12,000円想定：20〜34個 × 12,000円 = **約24万円〜41万円/月**

人件費（時給1,200円の機会費用）を差し引いた**実質利益ベース**では、6-1/6-2節の実質利益単価（1個あたり約6,300円[シャドウアート8,000円時]〜約8,600円[リソフェイン12,000円時]）を用いると：

- シャドウアート中心：81〜135個 × 約6,334円 = **約51万円〜85万円/月**
- リソフェイン中心：54〜90個 × 約5,000円 = **約27万円〜45万円/月**

**総合すると、A1 mini 1台・個人自宅運用という制約下での現実的な月間上限は、売上高ベースで概ね40万〜110万円、人件費差引後の実質利益ベースで概ね25万〜85万円のレンジ**に収まると推定される。商品ミックス（低単価・高回転のシャドウアート寄りか、高単価・低回転の高品質リソフェイン寄りか）で大きく変動するため、単一の数値ではなくレンジで捉えるのが妥当。

# 実測データ: 本リポジトリの `line_art_stl.py` が生成するSTLの体積・重量

このセッションで実際にスクリプトを実行し、生成STLの体積を `trimesh` で計測した値。
推定値ではなく実測値。

- 入力画像: `samples/test_silhouette.png`（同梱のテスト画像）
- 計測方法: `trimesh.load(stl).volume`（mm³）→ cm³ に換算 → PLA密度 1.24 g/cm³ を掛けて重量
- 注意: これは**STLの体積**。スライサーが実際に押し出す量は、この形状がほぼ薄肉ソリッドのため
  ほぼ同等（±10%）と見込めるが、ブリム/パージ/スカートで実測は数g上振れする。

## ここから直接言えること

1. **材料費は極めて小さい。** 主力サイズ（150mm角・厚み2mm）で **27g**。
   PLA 1kg を 2,500〜3,500円で買うなら材料費は **68〜95円/個**。
   価格の下限を材料費が縛ることはない → 原価の主役はフィラメントではなく「時間」。
2. **A1 mini(180mm)のサイズ上限は デザイン164mm＋枠8mm＝外形180mm がぴったり限界。**
   実運用では反り/ブリム/ノズル逃げを考えて **デザイン150mm・外形166mm が安全な最大**。
   つまり「A4サイズ以上の大判」は1枚では物理的に作れない → 分割パネル化（READMEの未実装TODO）が
   商品ラインを広げる際の技術的前提になる。
3. 円形・六角形は同じ外形サイズでも正方形より材料が 15〜25% 少ない（面積が小さいので当然）が、
   材料費が安いので価格差の根拠には使えない。**形状は価格ではなくデザイン訴求の差別化要素**。
4. 厚み 2mm → 3mm で重量が 27g → 41g（+50%）。それでも材料費差は +40円程度。
   厚みは「原価」ではなく「反り・印刷時間・質感」の観点で決めるべき。

## 2. 親レポートからの改訂点

### 改訂1: 「需要の実在性」の判定を保留から確定へ

**親レポートの記述（誤り）**
> 出品が少ない理由が「誰も気づいていないから」なのか「やってみたけど売れないから」なのかを、
> この調査では区別できません。

**改訂後**

区別できる。**「試したが売れなかった」側の証拠が明確に優勢**である。根拠は3つ:

1. 実際に出品した作家が**レビュー0件のまま販売を停止**している
2. メルカリの3Dプリント作品120件に**1件も存在しない**（出品すらされていない／撤退済み）
3. 検索需要が**測定不能**

「気づかれていないだけ」であれば、誰かが出品して細々とでも売れているはずである。
その痕跡がない。評価Dは確定とする。

### 改訂2: 推奨価格を引き下げ

**親レポートの価格表は市場実勢と乖離していた。** minneの実勢2,000〜5,000円、
メルカリ1,000〜3,000円という実データに対し、L 5,800円／LL 6,800円は上限を超えている。

| プラン | 親レポート | **改訂後** | 根拠 |
|---|---|---|---|
| S（100mm角） | 2,800円 | **2,800円**（据置） | minne下限帯。入口商品・レビュー獲得用 |
| M（130mm角） | 4,500円 | **4,500円**（据置） | 内祝いの「半返し」相場（2,500〜5,000円）に合致 |
| L（150mm角） | 5,800円 | **4,800〜5,500円** | minne照明の上位帯上限に接地させる |
| LL（164mm角） | 6,800円 | **廃止を推奨** | サイズ展開の手間に対しリターンが薄い |

**5,000円前後に集約するのが実勢に最も整合する。**
8,000円以上を取るには、Instagramでブランドを確立しプラットフォーム外（BASE等）で売る必要があり、
それは1〜2年かかる事業になる。

### 改訂3: 商品Cの位置づけ — 「競合が濃い」から「需要が実証された唯一の領域」へ

**親レポートは商品Cを「競合が濃いため優先度3番目」としたが、対立軸の捉え方が不十分だった。**

実データが示す構図は次の通り:

> **需要が実証されている市場（手形足形：1万円超でレビュー数百件）で下位互換品を売るか、
> 需要の証拠がない市場（写真アート）で唯一の商品を売るか。**

ただし、商品Cについての技術的評価は変わらない:

- 既存競合（Le Feuille等）は**物理型取り＋石膏キャスト**で、指の丸み・爪・シワの深さを再現している
- 2D画像からの押し出しは**シルエットのみ**で、Z軸情報は撮影段階で失われている
- **1万円超の価格帯では戦えない**（下位互換であるため）
- ラインスクリーン方式の転用は技術的に不適合（実機検証済み。親レポート§6）

3本のAIすべてが独立に同じ結論に達している。特にラインスクリーンの不適合については、
別セッションClaudeが計算で予測した内容（「指1本＝線3本」「モアレが出る」「ピッチを細かくすると
線幅下限0.2mmがノズル径0.4mmで印刷不能」）が、こちらの実機検証結果と完全に一致した。

**結論**: 商品Cをやるならシルエット押し出しの別実装で、**3,500〜5,000円の別ポジション**（型取り不要・
短納期・軽量）に限る。1万円帯は狙わない。

### 改訂4: リソフェイン否定の「理由」を差し替え

**親レポートの論拠は的がズレていた。**

親レポートは「Bambu Studioに生成機能があるので参入障壁ゼロ」を主たる否定理由としたが、
これは**「他の売り手が参入しやすい」という話であって、「顧客が自作するから買わない」話ではない**。
子どもがいる層で3Dプリンタを所有し自作する人は少数であり、顧客のDIY能力は脅威ではない。

**改訂後の否定理由**（DIY論ではなく実証データに基づく）:

1. minneの実例が**レビュー0件・販売休止**（試して売れなかった証拠）
2. メルカリ上位120件に**存在しない**
3. 検索需要が**測定不能**（日本語の一般名詞が「リトフェイン／リソフェイン／リトファン／透かし彫刻」
   と分裂しており、指名検索が成立しない）
4. Etsyの海外相場も**2,500〜6,000円のレッドオーシャン**

**ただし「価値ゼロ」ではない。** 追加開発コストが実質ゼロ（Bambu Studioで生成できる）で
在庫も持たないため、**「看板にしないが、メニューには載せる」**のが正しい扱い。

## 3. 新規の発見 — 小型はリソフェインが向く

3本のAIレポートのいずれも指摘していないが、突き合わせから導かれる重要な帰結。

**シャドウアートは幅0.5mmの細線の集合体であり、握れば折れる。**
別セッションClaudeが安全性の項で指摘した「線幅0.5mm × 厚み2mm の PLA リブは子どもが握れば折れ、
破片は誤飲サイズになる」は、持ち歩き用途では致命的な欠点になる。

対してリソフェインは中実の板なので構造的に丈夫。したがって:

| 用途 | 適する方式 | 理由 |
|---|---|---|
| 壁掛け・据え置き（大型） | **シャドウアート** | LED不要、差別化あり、細線でも破損しない |
| 持ち歩き（小型・キーホルダー） | **リソフェイン** | 中実で折れない、細線構造がない |

「リソフェインを捨てる」ではなく「**リソフェインは小型で使う**」が正しい住み分けである。

### キーホルダーの採算（50×60mm・厚3mm想定）

```
材料 8.3g × 2.8円/g          = 23円
送料 クリックポスト（安全側）  = 185円
梱包                          = 20円
手数料 minne 10.56%（1,800円） = 190円
─────────────────────────────────
販売価格 1,800円 → 粗利 1,382円（76.8%）
　　　　　　　　　  人件費(25分×1,200円/h)控除後 約880円
印刷時間 40〜70分［推定］
```

**ただし単体では商売にならない。** 写真の受け取り・調整・顧客とのやり取りの手間は、
1,800円の商品でも5,800円の商品でも**ほぼ同じ**である。低単価カスタムオーダーは手間倒れの典型。

### 推奨: セット販売の部品として使う

> **「壁掛け1枚（ご自宅用）＋ キーホルダー3個（祖父母・親戚に配る用）＝ 9,800円」**

- **1注文あたりの手間は1件分のまま、単価が上がる**（低単価カスタムオーダーの弱点を回避）
- 「祖父母・親戚に配る」は日本のギフト文化と噛み合う（親レポート§7の「祖父母への贈り物」訴求と接続）
- キーホルダー単品売りより明確に収益構造が良い

**安全上の注意**: キーホルダーは**親が持ち歩くもの**として設計・表示すること。
赤ちゃんが握る前提の訴求にすると、子供PSCマーク制度の射程に入るリスクがある。

## 4. Instagram戦略の具体化

### 4-1. 広告は出さない（3本のAIが一致）

Geminiの試算:

```
月20,000円 ÷ CPC100円 = 約200クリック
カスタムオーダーのCVR 0.5〜1.0% → 月2件
CPA = 10,000円　対して販売価格5,000円（粗利3,800円）
→ 回すほど赤字が拡大する
```

**単価が広告費を払える水準に達していない。予算を増やしても解決しない構造的な問題である。**

### 4-2. ショート動画（リール）は、この商品には適している

この商品には他の商品にない武器がある。**「変化の瞬間」が2つあること。**

1. 3Dプリンタの造形過程（何ができるか分からない → 完成する）
2. 光を当てて像が浮かぶ瞬間（ただの板 → 写真）

どちらも**3秒で理解でき、かつ見たことがない**。リールのアルゴリズムは視聴維持率を評価するため、
この2つは素材として強い。

**ただし最大の罠がある:**

> **3Dプリンタを主役にするとリーチは伸びるが、買わない層（同好の士＝自分で作れる人）が集まる。**

プリンタを主役にせず、**「子どもの写真」を主役にする**設計が必須。

### 4-3. ローンチ形式は有効。ただし順番が逆

「制作ストーリーを随時紹介 → 数日後に発売開始」という手法自体は有効。
ただし**これはフォロワーが既にいるアカウントの手法**であり、0フォロワーでカウントダウンしても
見ている人がいない。正しい順番は以下。

| 期間 | やること | 販売 |
|---|---|---|
| **Day 1–30** | 「光を当てる瞬間」「造形タイムラプス」のリールを**週4本**。プロフィールは「販売準備中」 | **売らない** |
| **Day 31–60** | Before/After（スマホ写真→完成品）を追加。DMで問い合わせが来たら個別対応 | 個別のみ |
| **Day 61–90** | **ここで初めてローンチ形式。**「◯月◯日 受注開始」を1週間前から予告し、制作過程を毎日投稿 | 正式販売 |

**Day 30 のKPI: リール平均リーチ 500超え。**
超えないなら、商品ではなくクリエイティブに問題がある（この商品の素材の強さなら500は取れるはず）。
ここで早期に判断できる。

### 4-4. その他の実務

- **ハッシュタグから商品名を捨てる。** `#リトフェイン` は検索需要が測定不能なので付けても無意味。
  `#出産内祝い` `#ハーフバースデー` `#ニューボーンフォト` `#孫` など**目的・イベント名**のタグで
  ギフトを探している層の検索意図に割り込む
- **Instagramだけに賭けない。** minneに並行出品（無料・在庫不要、Googleにインデックスされる）。
  ただしminne照明カテゴリは上位がレビュー1,995件という勝者総取り構造なので期待値は低く見積もる
- **サンプルは自分の子・ペット・風景で作る。** 顧客の子の顔を出さずに量産でき、
  著作権・肖像権の問題も同時に回避できる

## 5. 検討に値する選択肢: ペットへの展開

別セッションClaudeの提案。**同じ技術資産で、より大きく法的リスクの低い市場が狙える。**

| 観点 | 赤ちゃん | ペット |
|---|---|---|
| 母集団 | 出生数67万人／年、**10年連続減少**、2026年は丙午で追加の下押し懸念 | 犬猫飼育頭数は桁が大きい |
| 写真の著作権 | **構造的リスク**（一番良い写真＝スタジオ撮影＝著作権はスタジオ） | **ほぼクリア**（飼い主が自分で撮った写真しかない） |
| 支出意欲 | 高い（シックスポケット） | 高い |
| 写真の適性 | 肌が明るくコントラストが出にくい場合がある | 毛並みのコントラストがラインスクリーンに向く可能性［要検証］ |

赤ちゃんに絞る動機が「自分の子で作りたいから」であればそれは正当だが、
**事業として最大化するならペットの方が有利**である可能性が高い。

## 7. 改訂後の総合評価

3本のAIが独立に**総合D評価**、かつ**「商品Aのみ、低コストで数ヶ月試す価値は否定しない」**という
同一の結論に達した。

| 項目 | 評価 | 備考 |
|---|---|---|
| 原価構造 | **A** | 材料56〜120円。原価は問題にならない |
| 技術的優位（商品A） | **B** | ラインスクリーンは純正ツール不在の唯一の領域。ただし優位性の賞味期限は短い |
| 参入障壁（商品B） | **E** | メーカーが無料提供。競争にならない |
| 技術的成立性（商品C） | **E** | ラインスクリーン方式は原理的に不適合（実機検証済み） |
| **需要の実在性** | **D（確定）** | 保留を解除。「売れなかった」証拠が優勢 |
| 市場の成長性 | **E** | 出生数10年連続過去最少、2026年は丙午 |
| 価格実現性 | **D** | 実勢2,000〜5,000円。親レポートの想定より低い |
| 集客の現実性 | **D** | フォロワー0から。広告は構造的に赤字 |
| 法的リスク | **C** | 著作権が構造的制約。規約設計で相当程度は管理可能 |
| **初期投資リスク** | **A** | ほぼゼロ。これが唯一かつ最大の続行理由 |
| **総合** | **D** | 「やらない方がいい」寄り。ただし追加の金銭的リスクがほぼゼロであるため、商品A単体を3ヶ月試すことは否定しない |

### 改訂後の推奨

1. **商品Aに絞る。** 価格は4,500〜5,500円に集約。LLサイズは廃止
2. **商品Bは小型キーホルダー専用**とし、セット販売の部品として使う（単体売りしない）
3. **商品Cは保留。** やるならシルエット押し出しの別実装で3,500〜5,000円帯
4. **広告は打たない。** 90日はリールのオーガニックリーチに全振り
5. **Day 30 でリール平均リーチ500を判定基準にする**
6. **ペットへの展開を並行検討する**（母集団・著作権リスクの両面で有利）

### 撤退ライン（3本の提案を統合）

| 時点 | これを達成できていなければ撤退 |
|---|---|
| 1ヶ月 | 実物を10点以上印刷し、家族以外の他人に見せて「欲しい」と言われる水準に到達 |
| 1ヶ月 | リール平均リーチ500超え |
| 3ヶ月 | Instagramフォロワー300人以上、かつ問い合わせ5件以上 |
| 6ヶ月 | 累計販売10件以上、レビュー5件以上 |
| 12ヶ月 | 月商5万円以上が3ヶ月連続 |

**特に3ヶ月時点を重視すること。**
「まだ知られていないだけ」と自分に言い続けられる期間は3ヶ月までである。

## 2. 親レポートからの改訂点

### 改訂1: 「需要の実在性」の判定を保留から確定へ

**親レポートの記述（誤り）**
> 出品が少ない理由が「誰も気づいていないから」なのか「やってみたけど売れないから」なのかを、
> この調査では区別できません。

**改訂後**

区別できる。**「試したが売れなかった」側の証拠が明確に優勢**である。根拠は3つ:

1. 実際に出品した作家が**レビュー0件のまま販売を停止**している
2. メルカリの3Dプリント作品120件に**1件も存在しない**（出品すらされていない／撤退済み）
3. 検索需要が**測定不能**

「気づかれていないだけ」であれば、誰かが出品して細々とでも売れているはずである。
その痕跡がない。評価Dは確定とする。

### 改訂2: 推奨価格を引き下げ

**親レポートの価格表は市場実勢と乖離していた。** minneの実勢2,000〜5,000円、
メルカリ1,000〜3,000円という実データに対し、L 5,800円／LL 6,800円は上限を超えている。

| プラン | 親レポート | **改訂後** | 根拠 |
|---|---|---|---|
| S（100mm角） | 2,800円 | **2,800円**（据置） | minne下限帯。入口商品・レビュー獲得用 |
| M（130mm角） | 4,500円 | **4,500円**（据置） | 内祝いの「半返し」相場（2,500〜5,000円）に合致 |
| L（150mm角） | 5,800円 | **4,800〜5,500円** | minne照明の上位帯上限に接地させる |
| LL（164mm角） | 6,800円 | **廃止を推奨** | サイズ展開の手間に対しリターンが薄い |

**5,000円前後に集約するのが実勢に最も整合する。**
8,000円以上を取るには、Instagramでブランドを確立しプラットフォーム外（BASE等）で売る必要があり、
それは1〜2年かかる事業になる。

### 改訂3: 商品Cの位置づけ — 「競合が濃い」から「需要が実証された唯一の領域」へ

**親レポートは商品Cを「競合が濃いため優先度3番目」としたが、対立軸の捉え方が不十分だった。**

実データが示す構図は次の通り:

> **需要が実証されている市場（手形足形：1万円超でレビュー数百件）で下位互換品を売るか、
> 需要の証拠がない市場（写真アート）で唯一の商品を売るか。**

ただし、商品Cについての技術的評価は変わらない:

- 既存競合（Le Feuille等）は**物理型取り＋石膏キャスト**で、指の丸み・爪・シワの深さを再現している
- 2D画像からの押し出しは**シルエットのみ**で、Z軸情報は撮影段階で失われている
- **1万円超の価格帯では戦えない**（下位互換であるため）
- ラインスクリーン方式の転用は技術的に不適合（実機検証済み。親レポート§6）

3本のAIすべてが独立に同じ結論に達している。特にラインスクリーンの不適合については、
別セッションClaudeが計算で予測した内容（「指1本＝線3本」「モアレが出る」「ピッチを細かくすると
線幅下限0.2mmがノズル径0.4mmで印刷不能」）が、こちらの実機検証結果と完全に一致した。

**結論**: 商品Cをやるならシルエット押し出しの別実装で、**3,500〜5,000円の別ポジション**（型取り不要・
短納期・軽量）に限る。1万円帯は狙わない。

### 改訂4: リソフェイン否定の「理由」を差し替え

**親レポートの論拠は的がズレていた。**

親レポートは「Bambu Studioに生成機能があるので参入障壁ゼロ」を主たる否定理由としたが、
これは**「他の売り手が参入しやすい」という話であって、「顧客が自作するから買わない」話ではない**。
子どもがいる層で3Dプリンタを所有し自作する人は少数であり、顧客のDIY能力は脅威ではない。

**改訂後の否定理由**（DIY論ではなく実証データに基づく）:

1. minneの実例が**レビュー0件・販売休止**（試して売れなかった証拠）
2. メルカリ上位120件に**存在しない**
3. 検索需要が**測定不能**（日本語の一般名詞が「リトフェイン／リソフェイン／リトファン／透かし彫刻」
   と分裂しており、指名検索が成立しない）
4. Etsyの海外相場も**2,500〜6,000円のレッドオーシャン**

**ただし「価値ゼロ」ではない。** 追加開発コストが実質ゼロ（Bambu Studioで生成できる）で
在庫も持たないため、**「看板にしないが、メニューには載せる」**のが正しい扱い。

## 3. 新規の発見 — 小型はリソフェインが向く

3本のAIレポートのいずれも指摘していないが、突き合わせから導かれる重要な帰結。

**シャドウアートは幅0.5mmの細線の集合体であり、握れば折れる。**
別セッションClaudeが安全性の項で指摘した「線幅0.5mm × 厚み2mm の PLA リブは子どもが握れば折れ、
破片は誤飲サイズになる」は、持ち歩き用途では致命的な欠点になる。

対してリソフェインは中実の板なので構造的に丈夫。したがって:

| 用途 | 適する方式 | 理由 |
|---|---|---|
| 壁掛け・据え置き（大型） | **シャドウアート** | LED不要、差別化あり、細線でも破損しない |
| 持ち歩き（小型・キーホルダー） | **リソフェイン** | 中実で折れない、細線構造がない |

「リソフェインを捨てる」ではなく「**リソフェインは小型で使う**」が正しい住み分けである。

### キーホルダーの採算（50×60mm・厚3mm想定）

```
材料 8.3g × 2.8円/g          = 23円
送料 クリックポスト（安全側）  = 185円
梱包                          = 20円
手数料 minne 10.56%（1,800円） = 190円
─────────────────────────────────
販売価格 1,800円 → 粗利 1,382円（76.8%）
　　　　　　　　　  人件費(25分×1,200円/h)控除後 約880円
印刷時間 40〜70分［推定］
```

**ただし単体では商売にならない。** 写真の受け取り・調整・顧客とのやり取りの手間は、
1,800円の商品でも5,800円の商品でも**ほぼ同じ**である。低単価カスタムオーダーは手間倒れの典型。

### 推奨: セット販売の部品として使う

> **「壁掛け1枚（ご自宅用）＋ キーホルダー3個（祖父母・親戚に配る用）＝ 9,800円」**

- **1注文あたりの手間は1件分のまま、単価が上がる**（低単価カスタムオーダーの弱点を回避）
- 「祖父母・親戚に配る」は日本のギフト文化と噛み合う（親レポート§7の「祖父母への贈り物」訴求と接続）
- キーホルダー単品売りより明確に収益構造が良い

**安全上の注意**: キーホルダーは**親が持ち歩くもの**として設計・表示すること。
赤ちゃんが握る前提の訴求にすると、子供PSCマーク制度の射程に入るリスクがある。

## 4. Instagram戦略の具体化

### 4-1. 広告は出さない（3本のAIが一致）

Geminiの試算:

```
月20,000円 ÷ CPC100円 = 約200クリック
カスタムオーダーのCVR 0.5〜1.0% → 月2件
CPA = 10,000円　対して販売価格5,000円（粗利3,800円）
→ 回すほど赤字が拡大する
```

**単価が広告費を払える水準に達していない。予算を増やしても解決しない構造的な問題である。**

### 4-2. ショート動画（リール）は、この商品には適している

この商品には他の商品にない武器がある。**「変化の瞬間」が2つあること。**

1. 3Dプリンタの造形過程（何ができるか分からない → 完成する）
2. 光を当てて像が浮かぶ瞬間（ただの板 → 写真）

どちらも**3秒で理解でき、かつ見たことがない**。リールのアルゴリズムは視聴維持率を評価するため、
この2つは素材として強い。

**ただし最大の罠がある:**

> **3Dプリンタを主役にするとリーチは伸びるが、買わない層（同好の士＝自分で作れる人）が集まる。**

プリンタを主役にせず、**「子どもの写真」を主役にする**設計が必須。

### 4-3. ローンチ形式は有効。ただし順番が逆

「制作ストーリーを随時紹介 → 数日後に発売開始」という手法自体は有効。
ただし**これはフォロワーが既にいるアカウントの手法**であり、0フォロワーでカウントダウンしても
見ている人がいない。正しい順番は以下。

| 期間 | やること | 販売 |
|---|---|---|
| **Day 1–30** | 「光を当てる瞬間」「造形タイムラプス」のリールを**週4本**。プロフィールは「販売準備中」 | **売らない** |
| **Day 31–60** | Before/After（スマホ写真→完成品）を追加。DMで問い合わせが来たら個別対応 | 個別のみ |
| **Day 61–90** | **ここで初めてローンチ形式。**「◯月◯日 受注開始」を1週間前から予告し、制作過程を毎日投稿 | 正式販売 |

**Day 30 のKPI: リール平均リーチ 500超え。**
超えないなら、商品ではなくクリエイティブに問題がある（この商品の素材の強さなら500は取れるはず）。
ここで早期に判断できる。

### 4-4. その他の実務

- **ハッシュタグから商品名を捨てる。** `#リトフェイン` は検索需要が測定不能なので付けても無意味。
  `#出産内祝い` `#ハーフバースデー` `#ニューボーンフォト` `#孫` など**目的・イベント名**のタグで
  ギフトを探している層の検索意図に割り込む
- **Instagramだけに賭けない。** minneに並行出品（無料・在庫不要、Googleにインデックスされる）。
  ただしminne照明カテゴリは上位がレビュー1,995件という勝者総取り構造なので期待値は低く見積もる
- **サンプルは自分の子・ペット・風景で作る。** 顧客の子の顔を出さずに量産でき、
  著作権・肖像権の問題も同時に回避できる

## 5. 検討に値する選択肢: ペットへの展開

別セッションClaudeの提案。**同じ技術資産で、より大きく法的リスクの低い市場が狙える。**

| 観点 | 赤ちゃん | ペット |
|---|---|---|
| 母集団 | 出生数67万人／年、**10年連続減少**、2026年は丙午で追加の下押し懸念 | 犬猫飼育頭数は桁が大きい |
| 写真の著作権 | **構造的リスク**（一番良い写真＝スタジオ撮影＝著作権はスタジオ） | **ほぼクリア**（飼い主が自分で撮った写真しかない） |
| 支出意欲 | 高い（シックスポケット） | 高い |
| 写真の適性 | 肌が明るくコントラストが出にくい場合がある | 毛並みのコントラストがラインスクリーンに向く可能性［要検証］ |

赤ちゃんに絞る動機が「自分の子で作りたいから」であればそれは正当だが、
**事業として最大化するならペットの方が有利**である可能性が高い。

## 7. 改訂後の総合評価

3本のAIが独立に**総合D評価**、かつ**「商品Aのみ、低コストで数ヶ月試す価値は否定しない」**という
同一の結論に達した。

| 項目 | 評価 | 備考 |
|---|---|---|
| 原価構造 | **A** | 材料56〜120円。原価は問題にならない |
| 技術的優位（商品A） | **B** | ラインスクリーンは純正ツール不在の唯一の領域。ただし優位性の賞味期限は短い |
| 参入障壁（商品B） | **E** | メーカーが無料提供。競争にならない |
| 技術的成立性（商品C） | **E** | ラインスクリーン方式は原理的に不適合（実機検証済み） |
| **需要の実在性** | **D（確定）** | 保留を解除。「売れなかった」証拠が優勢 |
| 市場の成長性 | **E** | 出生数10年連続過去最少、2026年は丙午 |
| 価格実現性 | **D** | 実勢2,000〜5,000円。親レポートの想定より低い |
| 集客の現実性 | **D** | フォロワー0から。広告は構造的に赤字 |
| 法的リスク | **C** | 著作権が構造的制約。規約設計で相当程度は管理可能 |
| **初期投資リスク** | **A** | ほぼゼロ。これが唯一かつ最大の続行理由 |
| **総合** | **D** | 「やらない方がいい」寄り。ただし追加の金銭的リスクがほぼゼロであるため、商品A単体を3ヶ月試すことは否定しない |

### 改訂後の推奨

1. **商品Aに絞る。** 価格は4,500〜5,500円に集約。LLサイズは廃止
2. **商品Bは小型キーホルダー専用**とし、セット販売の部品として使う（単体売りしない）
3. **商品Cは保留。** やるならシルエット押し出しの別実装で3,500〜5,000円帯
4. **広告は打たない。** 90日はリールのオーガニックリーチに全振り
5. **Day 30 でリール平均リーチ500を判定基準にする**
6. **ペットへの展開を並行検討する**（母集団・著作権リスクの両面で有利）
7. **結婚式ウェルカムスペース路線を検討する（§8）** — 用途としては本追補で最も有望。
   この用途に限りリソフェインの評価を上方修正する
8. **【最優先】カメラマンとの提携を検討する（§9）** — 本事業の最大の弱点である
   「需要D・集客D」を構造的に解消しうる唯一の経路。かつ検証が面談1回で済む。
   §8より先に着手すべき

### 撤退ライン（3本の提案を統合）

| 時点 | これを達成できていなければ撤退 |
|---|---|
| 1ヶ月 | 実物を10点以上印刷し、家族以外の他人に見せて「欲しい」と言われる水準に到達 |
| 1ヶ月 | リール平均リーチ500超え |
| 3ヶ月 | Instagramフォロワー300人以上、かつ問い合わせ5件以上 |
| 6ヶ月 | 累計販売10件以上、レビュー5件以上 |
| 12ヶ月 | 月商5万円以上が3ヶ月連続 |

**特に3ヶ月時点を重視すること。**
「まだ知られていないだけ」と自分に言い続けられる期間は3ヶ月までである。

## 8. 新路線: 結婚式ウェルカムスペース向けリソフェイン

**本追補で検討した中で最も有望な用途。この用途に限り、リソフェインの評価を上方修正する。**

### 8-1. なぜ有望か — リソフェインの弱点が長所に反転する

親レポートおよび本追補§2でリソフェインを否定した論拠の一つは「LED必須＝原価と設置場所の制約」だった。
**ウェルカムスペースではこの制約がすべて反転する。**

| リソフェインの弱点 | 赤ちゃん市場での意味 | ウェルカムスペースでの意味 |
|---|---|---|
| バックライトが必須 | 子供部屋に電気製品を増やしたくない | **会場は照明を落とす。光るものが有利** |
| 電源が必要 | 飾れる場所が限られる | **テーブルに電源がある前提の空間** |
| LED原価 1,550円 | 単価3,900円に対して重すぎる | **単価1万円超なら誤差** |
| 暗くないと映えない | 昼間の部屋ではただの板 | **披露宴会場は暗い** |

加えて、写真アート路線に欠けていた要素が2つ揃う。

1. **検索需要が実在する。** 「リトフェイン」は検索ボリューム測定不能だったが、
   「ウェルカムボード」は明確な指名検索が存在する市場である。
   **顧客が探している言葉が存在する**——これが前回の調査で決定的に欠けていた要素。
2. **納期が読める。** 結婚式は3〜6ヶ月前から準備が始まる。挙式日は動かないが**リードタイムが長い**。
   「2ヶ月前締切」とすればA1 mini 1台でも計画生産で回せる。
   出産直後に急に需要が立つ赤ちゃん市場より、単機運用と相性が良い。

### 8-2. 価格相場（実データ）

| 項目 | 相場 | 出典 |
|---|---|---|
| ウェルカムボード オーダーメイド | **2万〜3万円**（式場手配はさらに高額。スキルマーケットは1万円以下も） | [結婚スタイルマガジン](https://www.niwaka.com/ksm/radio/wedding/item/welcome-board/06/)、[ココナラマガジン](https://coconala.com/magazines/528) |
| ウェルカムスペース装飾全体 | **5万〜10万円** | [yuen wedding](https://yuen-wedding.com/column/387) |
| プチギフト | 200〜500円、**平均268円** | [アンシェウェディング](https://ancie.jp/blog/hikidemono/petit-gift/petitgift-marketprice/) |
| 引き出物 | 全国平均 6,260円、平均2.9品 | [アンシェウェディング](https://ancie.jp/blog/hikidemono/gift-manners/how-to-select/) |

**1万〜1.5万円が「安い」と感じられる、本調査で確認した唯一の市場である。**
minneの照明カテゴリが2,000〜5,000円で頭打ちだったのとは価格帯の階層が異なる。
結婚式は相場感が緩く、かつ差別化欲求が高いため「見たことがない」がそのまま価値になる。

### 8-3. サイズ制約への解 — 168mm問題は解ける

**メインのウェルカムボードとしては166mm角は小さすぎる。** 標準はA3(297×420)〜A2(420×594)で
正面から競合しても勝てない。この点は事実として認める。ただし解が3つある。

#### 案1: 行灯・ランタン型（4面立体）★推奨

150mm角パネル4枚を組んで立方体にする。

- **「小さい」が欠点にならない。** 平面ではなく立体なので存在感が出る
- **光ることが必然になる。** ウェルカムスペースの暗さと噛み合う
- **A1 miniの180mm制約が無関係になる。** パネルを1枚ずつ刷って組み立てるだけ
- 4面あるため「前撮り4カット」「二人の生い立ち」など**物語を載せられる**

採算試算（4面＋LED＋台座、販売価格15,000円）:

```
材料 4面 × (150×150×1.8mm) = 162cm³ × 1.24 = 201g × 2.8円/g = 563円
LEDユニット                                                  = 1,550円
台座・組立部材［仮定］                                        = 500円
梱包                                                          = 150円
送料 宅急便60サイズ                                           = 750円
手数料 minne 10.56%                                          = 1,584円
──────────────────────────────────────────────────
粗利 9,903円（66.0%）／人件費(組立込90分×1,200円/h)控除後 約8,100円
印刷時間 24〜36時間［推定］→ 月10〜20個が上限
```

月10〜20個は結婚式の受注ペースとしては十分。**印刷時間はボトルネックにならない。**

#### 案2: 3枚組・5枚組のギャラリー構成

166mm角を複数並べる。**分割の継ぎ目問題を「意図的な複数枚構成」に転換する**発想。
販売価格15,000〜20,000円。

#### 案3: 脇役ポジション

メインボードは他で用意してもらい、その隣に置く光る小物として6,000〜8,000円。
競合を避けられるが単価が下がる。

#### 非推奨: A3を4分割して1枚に見せる

リソフェインは連続階調のためシャドウアートほど継ぎ目が致命的ではないが、
**バックライトは継ぎ目を隠すどころか強調する。光ムラが必ず出る。**

### 8-4. 難点（4つ）

#### ① 著作権リスクは赤ちゃん市場より「悪化」する

**最大の懸念。** 赤ちゃん市場には「スマホで撮った写真でお作りします」という逃げ道があった（親レポート§8-1）。
ウェルカムスペースに飾る写真は**前撮り・フォトウェディングでほぼ100%プロ撮影**であり、
この逃げ道が塞がる。

**対処法**: 顔のアップにこだわらない商品設計にする。

- 引きのシルエット、後ろ姿、手元（指輪）、二人の影
- これらは**スマホで撮影可能**であり、かつ意匠として成立し、
  ラインスクリーン・リソフェインどちらにも向く構図

「顔がはっきり写った前撮り写真」を前提とする設計にすると、権利リスクが常時つきまとう。
**この構図制約を最初から商品コンセプトに織り込めるかが成否の分かれ目。**

#### ② ウェルカムボード市場はレッドオーシャン

minneには既に**アクリル製の写真ウェルカムボードがA5/A4/A3/A2の4サイズ展開**で存在する
（[該当商品](https://minne.com/items/40433522)、写真補正無料）。
ウェルカムボードはハンドメイド最激戦カテゴリの一つ。

ただし**リソフェイン型（立体・透過光）の競合は本調査では見当たらなかった**。
同じ「写真ボード」でも別カテゴリとして立てられる可能性はある。**要確認事項**。

#### ③ 失敗の代償が重い

一生に一度で、日程が動かない。**予備を1枚多く刷る前提**にすること
（原価が1.2〜1.5倍になるが、そうすべき）。個人事業で受けるには責任の重い商材である。

#### ④ プチギフト・引き出物路線は成立しない

本追補§3のキーホルダー案を結婚式に転用してはいけない。

- **プチギフト相場は平均268円**。材料費23円でも手間を考えれば絶対に合わない
- 引き出物（平均6,260円）なら単価は届くが、**新郎新婦の写真入りグッズは
  「もらって困るギフト」の代表格**であり、狙うべきではない

**ウェルカムスペース本体（＝二人が自分のために買うもの）に絞ること。**

### 8-5. 検証方法

この路線は赤ちゃん路線より**検証が早く終わる**。

1. **minne / Creemaで「ウェルカムボード 光る」「ウェルカムボード アクリル LED」を検索**
   → リソフェイン型の競合の有無、レビュー件数
2. **Instagramで `#ウェルカムスペース` `#ウェルカムボード` を見る**
   → 花嫁は必ず投稿するため、実際に何が使われているかが一目で分かる。
   **赤ちゃん市場と異なり、顧客が自発的に大量のUGCを出している市場である**（集客上も有利）
3. **行灯型を1個試作し、暗い部屋で光らせる**（材料563円）
   → **ここで自分が感動しないなら、その先はない**

### 8-6. 評価

| 項目 | 赤ちゃん市場 | **ウェルカムスペース** |
|---|---|---|
| 検索需要の実在 | **D**（測定不能） | **B**（「ウェルカムボード」は指名検索あり） |
| 価格帯 | 2,000〜5,000円 | **10,000〜30,000円** |
| リソフェインの適性 | **E**（LEDが足枷） | **A**（暗い会場・電源あり） |
| 納期の管理しやすさ | C（出産直後に需要が立つ） | **B**（3〜6ヶ月前から準備。計画生産可） |
| 著作権リスク | C（スマホ写真で回避可） | **D**（前撮り写真が主。構図設計で回避要） |
| 競合の密度 | B（薄い＝需要も薄い） | **D**（レッドオーシャン。ただし透過光型は不在） |
| UGC・口コミの起きやすさ | C | **A**（花嫁は必ず投稿する） |
| リピート性 | B | **E**（完全な単発。ただし口コミは強い） |

**総評**: 「映えるから」ではなく、①検索需要が実在する ②価格帯が2〜3倍 
③リソフェインの構造的弱点がすべて長所に反転する ④納期が読める、の4点により、
**赤ちゃん向け写真アート路線より勝ち目がある**と判断する。

一方、著作権の逃げ道が狭まる点とウェルカムボード市場そのものの混雑度は赤ちゃん市場より厳しい。
**「顔写真を大きく使わない構図」を商品設計に最初から織り込めるかが分かれ目。**

## 9. 【最優先】カメラマンとの提携路線

**本追補で検討した中で最も重要な選択肢。§8のウェルカムスペース路線より先に着手すべき。**

### 9-1. これが解決するのは著作権ではない — 「需要D・集客D」である

親レポートおよび本追補を通じて、本事業の最大の弱点は法務ではなく
**需要の実在性D・集客の現実性D**であった。フォロワー0から売上まで3〜6ヶ月、
広告はCPA1万円で構造的に赤字、検索需要は測定不能。
**「作れるが誰にも届かない」**が本質的な問題である。

カメラマンは、その問題を丸ごと保有している。

| 本事業の弱点 | カメラマンが既に持っているもの |
|---|---|
| 顧客がいない | **ターゲット層そのものの顧客リスト** |
| 信頼がない | **すでに対価を支払った関係** |
| 集客に3〜6ヶ月かかる | **納品時・撮影時という販売機会** |
| 広告CPAが1万円で赤字 | **集客コストゼロ** |
| 検索需要が存在しない（評価D） | **検索される必要がない** |

**本追補§4のInstagram戦略は、この経路では大部分が不要になる。**

加えて、Geminiが指摘した品質リスク——「顧客のスマホ写真は照明が素人であるため、
シャドウアートに変換した際に顔に不自然な影が入りクレームに発展する」——も解消する。
プロ撮影の写真は高コントラストかつ照明が適切であり、
**ラインスクリーン・リソフェインの双方にとって最適な素材**である。歩留まりが上がる。

### 9-2. これは「お願い」ではなく相手にもメリットのある提案である

この認識を持たずに交渉すると失敗する。カメラマン側の事情は以下の通り。

- 撮影業は**データ納品で終わると単価が頭打ち**であり、アップセル商材を常に求めている
- ニューボーンフォト・前撮りは価格競争が激しく、**「うちだけの特典」は差別化になる**
- 受注生産のため**在庫リスクがゼロ**。導入を断る理由が少ない
- **自分の作品が立体になる**という体験自体が、写真家にとって訴求力を持つ

一方的な依頼ではなく、**相手の商品ラインを増やす提案**として構成できる。

### 9-3. 最大の地雷 — 切り出し方

**カメラマンは著作権に職業的に極めてセンシティブである。**

「あなたが撮った写真を加工して販売したい」という切り出し方は、言い方次第で
**「私の作品を無断で改変して金銭を得たい」**と受け取られる。ここが唯一かつ最大のリスク。

**回避策は一つ。実物を持参すること。**

> 「うちの子を撮っていただいた写真で、こんなものを作ってみたんです。見てもらえますか」

この入り方であれば:

- 相手にとって「自分の作品が立体になった」という**贈り物**の文脈になる
- 口頭説明では絶対に伝わらない「光を当てた瞬間」を実物で示せる
- ビジネスの話は、相手が関心を示してから出せばよい

**初回の面談でビジネスの話をしないこと。** 実物を見せ、反応を見る。それだけでよい。

### 9-4. 提携の型（軽い順）

| 型 | 内容 | 取り分 | 位置づけ |
|---|---|---|---|
| **A: 許諾のみ** | 「当スタジオ撮影写真の加工を許可する」旨の書面を得る。顧客獲得は自力 | 全額 | **最も軽い。ここから始める** |
| **B: 紹介** | カメラマンが紹介し、こちらが直接受注。紹介料15〜30% | 70〜85% | 軽い |
| **C: 卸（OEM）** | カメラマンが自社商品として販売、こちらは製造のみ | 40〜60% | 営業不要だが単価が下がる |
| **D: 共同商品** | 「撮影＋立体アート」のセットプランを共同開発 | 応相談 | **最も価値が高いが実績が必要** |

**Aから入りDを目指すのが正しい順序。** いきなりDを提案すると重く受け取られる。

### 9-5. 事前に固めておくべきこと

**① 供給責任の上限を先に決める**

A1 mini 1台である。前撮りシーズン等に注文が集中すると捌けない。
**「月◯件まで」を最初に明示すること。** 約束を履行できないことが最も信用を毀損する。
少なめに申告して超過分を断る方が、逆よりはるかに安全。

**② カメラマンの既存商流を壊さない**

相手が既にアルバム・パネル・データ販売を行っている場合、競合になり得る。
**「アルバムの代わり」ではなく「アルバムに追加する一品」**として位置づけること。

**③ 書面を必ず作る**

口約束は不可。最低限以下を明記する。

- 許諾範囲（複製・**翻案**・SNS掲載）。特に**翻案（加工）を明示的に含めること**
- 対価と支払い方法
- 期間と解約条件
- クレジット表記（「Photo by ◯◯」を入れると相手側のメリットになる）

**④ 単一依存のリスクを認識する**

関係が切れれば事業が停止する。初期は問題ないが、軌道に乗った段階で2人目を確保すること。

### 9-6. 提携が成立しなくても面談には価値がある

**カメラマンは「顧客が写真に何を求めているか」を知る最良の情報源である。**

本調査は、環境制約によりminneの出品件数・レビュー数・メルカリのSOLD価格を取得できなかった。
他AI2本が一部を補完したが、それでも「需要が実在するか」は推測の域を出ていない（評価D）。

**カメラマンに1時間話を聞けば、本調査で3日かけて取得できなかった情報が得られる。**

- 顧客はデータ以外に何を購入しているか
- 上限いくらまで支出するか
- 「写真を飾りたい」と言う顧客がどの程度いるか
- 祖父母向けの需要が実際に存在するか（親レポート§7の最重要仮説の検証）

**提携が成立しなくても面談は元が取れる。** 売り込みではなく、教わりに行く姿勢で臨むこと。

### 9-7. 評価の変化

| 項目 | 単独実施 | **カメラマン提携** |
|---|---|---|
| 需要の実在性 | D | **C〜B**（実顧客に直接アクセス可能） |
| 集客の現実性 | D | **B**（Instagram不要） |
| 法的リスク | C | **B**（権利者と直接契約） |
| 写真素材の品質 | C（スマホ写真は照明が素人） | **A**（プロ撮影＝高コントラスト） |
| スケール性 | C | **D**（相手のキャパに縛られる） |
| **検証速度** | **3ヶ月** | **面談1回** |

最終行が決定的である。本追補§4のInstagram計画は「Day 30でリール平均リーチ500」を
判定基準とする設計だったが、**カメラマン経路であれば1回の面談でほぼ答えが出る。**
「顧客に紹介いただけそうか」への反応を見れば判断できる。

### 9-8. 次のアクション

**まず自分の子の写真で1枚作り、それを持って会いに行く。材料費85円。**

これが本追補全体を通じて、最も費用対効果の高い次の一手である。

なお、相談相手が結婚式の前撮りも手掛けているなら、§8のウェルカムスペース路線も
同じ面談で検証できる。ニューボーンフォト系のみであれば赤ちゃん路線の検証に集中すること。
